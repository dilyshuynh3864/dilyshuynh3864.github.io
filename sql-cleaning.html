Data Cleaning
&
Sanitation in SQL

Optimizing raw housing infrastructure records to achieve production-grade data integrity using advanced T-SQL manipulation techniques.

Core Technologies Implemented

Transact-SQL (T-SQL) Self-Join Aggregation Window Functions (ROW_NUMBER) Common Table Expressions (CTEs) String Boundary Deconstruction Conditional Formatting (CASE WHEN)

The Data Problem

Raw operational database tables frequently contain missing entries, inconsistent datetime formats, unparsed compound address strings, and absolute row duplicates. The objective of this project was to take an unorganized Nashville housing dataset and completely standardize its internal topology using optimized SQL queries before migration.

Technical Actions & Pipeline Highlights

To systematically transition the housing dataset from raw records into an enterprise-ready relational state, the data pipeline executed four core engineering actions:

SQL Engineering Strategy Algorithmic Mechanism & Query Optimization
Self-Join Data Imputation Identified critical missing paths in PropertyAddress rows. Engineered a conditional **Self-Join** operation linking records back to themselves based on unique ParcelID matches, executing an ISNULL() imputation query to populate missing addresses automatically.
String Deconstruction (1NF) Resolved structural violations of First Normal Form (1NF) where monolithic text address blocks held multiple values. Employed SUBSTRING, CHARINDEX, and PARSENAME token masking to split compound strings into atomic columns (Address, City, State).
Windowed Deduplication Constructed partition-based window operations utilizing ROW_NUMBER() OVER (PARTITION BY...) mapped across explicit composite keys (ParcelID, PropertyAddress, SalePrice, SaleDate). Wrapped inside a **CTE** to safely purge absolute row duplicates.
Conditional Value Tuning Standardized logical data noise within boolean-style attributes where mixed strings ('Y', 'Yes', 'N', 'No') existed simultaneously. Regularized the entire data column into deterministic binary tags via scalable CASE WHEN logic.

Key Outcomes & Data Integrity Metrics

The successful execution of the sanitation script delivered measurable performance and structural improvements to the database ecosystem:

  • 100% Normalized State: Effectively stripped down the messy flat-file topology into clean, normalized fields, resolving data redundancy and ensuring structural integrity before any target server migration.
  • Advanced Geospatial Filtering: By splintering multi-value text address strings into individual atomic blocks, down-stream analytics models can now execute lightning-fast regional aggregations and city-specific property sales sorting.
  • Storage Optimization & Sanitation: Removing absolute row duplicates and dropping unused legacy metadata columns significantly trimmed table weight, ensuring that the database serves as a lean "Single Source of Truth."
