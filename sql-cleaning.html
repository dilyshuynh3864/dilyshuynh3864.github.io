Enterprise Data Cleaning
& Sanitation in SQL

Optimizing raw housing infrastructure records to achieve production-grade data integrity using advanced T-SQL manipulation techniques.

The Data Problem

Raw operational database tables frequently contain missing entries, inconsistent datetime formats, unparsed compound address strings, and absolute row duplicates. The objective of this project was to take an unorganized Nashville housing dataset and completely standardize its internal topology using optimized SQL queries before migration.

Technical Actions & Pipeline Highlights

  • Format Standardization: Converted dynamic, messy date fields into consistent, industry-standard SQL Date formats to optimize baseline querying.
  • Property Address Parsing: Utilized character boundary analysis (SUBSTRING, CHARINDEX) and string parsing (PARSENAME) to cleanly isolate composite text addresses into individual, queryable columns (Address, City, State).
  • Redundancy Elimination: Engineered partition-based window functions (ROW_NUMBER() OVER (PARTITION BY...)) to dynamically discover and safely purge duplicate data entries without service interruption.
  • Value Transformation: Standardized chaotic boolean-style fields (replacing mixed 'Y'/'Yes' and 'N'/'No' inputs) using robust CASE WHEN statements.
