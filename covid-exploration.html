COVID-19 Cloud Data Exploration
Advanced Querying and Outbreak Metrics

Processing millions of global coronavirus records to compute transmission velocities and dynamic rolling sums.

The Data Problem

Massive global healthcare datasets require significant memory profiles and complex data grouping logic before rendering meaningful insights. The target was to write optimized queries capable of parsing geographic infection growth rates and tracking population vaccination coverage chronologically over millions of raw log entries.

Technical Actions & Query Strategies

  • Relational Table Joins: Aggregated multi-layered statistical datasets by writing optimized JOIN clauses matching historical infection timelines against rolling vaccination tracking arrays.
  • Rolling Sum Windowing: Engineered analytic partitions (SUM(CAST(...)) OVER (PARTITION BY... ORDER BY...)) to build real-time rolling calculations of global medical treatments.
  • Memory Optimization via CTEs: Leveraged Common Table Expressions (CTEs) and temporary staging tables to store intricate mathematical calculations, reducing core CPU processing cycles.
  • Dynamic View Creation: Provisioned enterprise data views to store critical trend queries, creating a clean data access layer for downstream visualization tools (Tableau/PowerBI).
