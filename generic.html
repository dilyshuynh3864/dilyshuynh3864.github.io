AWS Cloud Infrastructure
Deployment Practicum

A multi-tier cloud environment architecture deployed within the AWS Learner Lab sandbox, simulating enterprise network isolation, persistent infrastructure provisioning, and edge performance optimization.

Project Core Objective

The goal of this self-directed infrastructure practicum was to transition localized full-stack applications into a resilient, production-ready cloud paradigm. By moving across six distinct engineering milestones (Tasks A through F), I successfully mapped out secure operational networking paths and tackled cloud dependency boundaries.

Architectural Components Implemented

  • Virtual Private Cloud (VPC) Topology: Created an isolated network space partitioned into deliberate Public Subnets (front-end facing) and Private Subnets (database and processing layers) with specialized Route Tables and Internet Gateways.
  • Secure Compute Provisioning: Launched and configured AWS EC2 server nodes, mapping inbound traffic boundaries using stateful Security Groups (Virtual Firewalls) restricting access to Ports 80 (HTTP) and 22 (SSH).
  • Data Persistence Layer: Integrated Amazon Elastic Block Storage (EBS) volumes attached to server nodes to guarantee log and database configuration persistence across continuous delivery lifecycles.
  • Edge Cache Optimization: Configured Amazon CloudFront distributions to act as a global Content Delivery Network (CDN), solving structural origin routing traps to provide minimal asset delivery latency.

Operational Insights & Troubleshooting

During deployment, explicit troubleshooting practices were required to handle network connectivity traps. Initial instances deployed within the subnets faced package resolution errors due to missing route table paths to the Internet Gateway. By auditing the network topology and injecting explicit gateway pointers for external traffic (0.0.0.0/0), environment functionality was fully restored. This hands-on practice built the definitive operational auditing and infrastructure analysis skills required for corporate cloud management.
